# transmission_in_queue
The flow visualization video and source code for modeling aerosol transmission in a queue are available on GitHub at https://github.com/junshiwang25/transmission_in_queue
The DNS flow-field data is provided as a release asset (about 97 MB). Open the [Releases](https://github.com/junshiwang25/transmission_in_queue/releases) section of this repository and download `dns-flow-fields_breath-speech.zip` from the latest release.
